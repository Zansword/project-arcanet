구조 설명 (2단계 계층 아키텍처)

ARCANET 프로젝트의 아키텍처는 상태 결정성과 렌더링·네트워크 처리를 명확히 분리하기 위해 총 2단계 계층으로 구성됩니다.

TIER 01 · CORE

1단계 — 아케이드 하드웨어 코어 라이브러리

Neo Geo, Namco System 12 등 실제 아케이드 보드의 CPU, 레지스터, 주요 칩의 에뮬레이션과 결정론적 상태(Deterministic State)를 보장하기 위한 메모리 구조를 담고 있는 코어 계층입니다.

입력을 반영해 상태를 갱신·저장하면서 렌더링을 위한 결과 데이터를 프론트엔드로 전송합니다. 과거의 에뮬레이터들과 달리 실제 CPU 스레드는 게임 데이터 교환과 시뮬레이션에 집중하고, 병목을 유발할 수 있는 그래픽 렌더링은 별도 자원이 담당하도록 분리해 단일 CPU 코어의 부담이 비교적 적은 구조를 구현하고자 했습니다.

TIER 02 · FRONTEND

2단계 — 에뮬레이터 프론트엔드

코어 옵션 설정, 그래픽 렌더링, 사운드 출력, 네트워크 세션 관리 및 동기화를 전담하는 계층입니다.

코어에서 출력되는 결과물만을 빠르게 연동하여 화면과 오디오로 표현하며, 프론트엔드가 코어 내부에 직접 영향을 주는 요소는 사전 코어 설정과 플레이어의 컨트롤 입력이 전부인 구조로 작동합니다.

Architecture (Two-Tier Design)

ARCANET separates deterministic hardware simulation from presentation and networking across two distinct tiers.

TIER 01 · CORE

Tier 1 — Arcade Hardware Core Library

Emulates real arcade board CPUs, registers, and custom chips (such as Neo Geo and Namco System 12) with a memory layout built to guarantee deterministic state snapshots and restores.

Updates state from inputs and passes frame output to the frontend while keeping heavy rendering off the core simulation thread to reduce single-core CPU bottlenecks.

TIER 02 · FRONTEND

Tier 2 — Emulator Frontend

Handles core configuration, graphics rendering, audio output, and network session management.

Consumes core outputs directly while restricting its influence on the core strictly to initial core settings and player control inputs.

설치 및 사용법

  • ROM 정책 안내 프로젝트 ARCANET은 합법적인 경로로 확보한 ROM을 최우선 목표로 지원합니다. MAME를 기본 베이스로 참고하였으나 직접 ROM 파일을 제공하지 않으며, 공식 구매 소프트웨어에서 ROM을 추출해 활용할 수 있는 안내와 도구는 다운로드 페이지에서 함께 제공할 예정입니다.
  • 설치 및 상세 설정 가이드 이미지를 곁들인 단계별 설치 및 네트워크 설정 가이드는 현재 일부 아키텍처 조정 작업이 마무리되는 대로 순차적으로 업데이트될 예정입니다.
