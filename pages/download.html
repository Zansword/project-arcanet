구성요소

  • 프론트엔드(.exe)사용자 인터페이스, 그래픽 렌더링, 사운드 출력 및 P2P/서버 네트워크 세션을 전담하는 Rust 기반 실행 계층입니다.
  • 아케이드 하드웨어 코어 라이브러리 (.dll)Neo Geo, Namco System 12 등 대상 기판의 CPU·메모리·주변 칩을 결정론적 구조로 에뮬레이션하는 C89 코어 모듈입니다.
  • 매치메이킹 서버 및 설정 파일 (.exe)유저가 직접 호스트 서버를 개설하고 관전·중도 참여 세션을 운영할 수 있는 커뮤니티용 add-on 서버입니다.(최대 200명)

Components

  • Frontend Executable (.exe)Rust-based frontend layer responsible for UI, graphics rendering, audio output, and network session control.
  • Arcade Hardware Core Libraries (.dll)Deterministic C89 core modules emulating CPUs, memory maps, and custom hardware for boards like Neo Geo and Namco System 12.
  • MatchMaking Server & Configuration(.exe)Components enabling user-hosted lobbies, spectating, and drop-in multiplayer sessions.(Maximum 200)

설치 및 사용법

  • ROM 정책 안내 프로젝트 ARCANET은 합법적인 경로로 확보한 ROM을 최우선 목표로 지원합니다. MAME를 기본 베이스로 참고하였으나 직접 ROM 파일을 제공하지 않으며, 공식 구매 소프트웨어에서 ROM을 추출해 활용할 수 있는 안내와 도구는 릴리즈 및 안내를 통해 함께 제공할 예정입니다.
  • 설치 및 상세 설정 가이드 이미지를 곁들인 단계별 설치 및 네트워크 설정 가이드는 현재 일부 아키텍처 조정 작업이 마무리되는 대로 순차적으로 업데이트될 예정입니다.

Setup & Usage

  • ROM Policy Project ARCANET prioritizes legally obtained ROMs. No ROM files are distributed directly; official purchase links and extraction utilities will be provided alongside releases.
  • Installation & Configuration Guide Illustrated step-by-step installation and netplay setup guides are currently on hold while final architectural refinements are completed.
