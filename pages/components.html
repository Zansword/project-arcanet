주요 구성요소

  • 프론트엔드 실행 바이너리 (abro.exe)사용자 인터페이스, 그래픽 렌더링, 사운드 출력 및 P2P/서버 네트워크 세션을 전담하는 Rust 기반 실행 계층입니다.
  • 아케이드 하드웨어 코어 라이브러리 (.dll)Neo Geo, Namco System 12 등 대상 기판의 CPU·메모리·주변 칩을 결정론적 구조로 에뮬레이션하는 C89 코어 모듈입니다.
  • 상태 스냅샷 및 Rollback 엔진프레임 단위 상태 저장·복원과 원격 입력 동기화를 처리하여 지연 없는 대전 및 3~4인 멀티플레이를 지원합니다.
  • 독자 커뮤니티 서버 및 설정 파일유저가 직접 호스트 서버를 개설하고 관전·중도 참여 세션을 운영할 수 있는 네트워크 구성 요소입니다.

Core Components

  • Frontend Executable (abro.exe)Rust-based frontend layer responsible for UI, graphics rendering, audio output, and network session control.
  • Arcade Hardware Core Libraries (.dll)Deterministic C89 core modules emulating CPUs, memory maps, and custom hardware for boards like Neo Geo and Namco System 12.
  • State Snapshot & Rollback EngineHandles frame-level state serialization and remote input synchronization for responsive 2–4 player netplay.
  • Community Server & ConfigurationComponents enabling user-hosted lobbies, spectating, and drop-in multiplayer sessions.
